# Documentation Map

Read in this order the first time:

1. [00-vision/VISION.md](00-vision/VISION.md) — what and why
2. [01-research/RESEARCH.md](01-research/RESEARCH.md) — what others did, what we took
3. [02-architecture/ARCHITECTURE.md](02-architecture/ARCHITECTURE.md) — the whole system, with diagrams
4. [04-plan/PLAN_OVERVIEW.md](04-plan/PLAN_OVERVIEW.md) then [ROADMAP.md](04-plan/ROADMAP.md) — how the work is organised
5. [06-guides/WORKFLOW.md](06-guides/WORKFLOW.md) — how to work a slice
6. The current wave in [04-plan/waves/](04-plan/waves/README.md)

| Folder | Contents | Changes when |
|---|---|---|
| `00-vision` | goals, non-goals | rarely |
| `01-research` | survey, census experiments | new evidence |
| `02-architecture` | architecture, memory map, boot protocol, Go hosting, nucleus ABI | a contract changes (same commit as code) |
| `03-decisions` | ADRs (immutable once accepted) | a significant decision |
| `04-plan` | backlog, roadmap, waves, slices | every slice (status) |
| `05-testing` | test strategy | new test kind |
| `06-guides` | setup, debugging, standards, workflow, glossary | as needed |
| `living` | **DEVLOG, BUGS_AND_MITIGATIONS, RISKS** | every session |
